# استمارة الزيارة الفنية لمدير/ة المدرسة

تطبيق عربي يعمل من المتصفح لإدخال مراحل الزيارة الفنية الثلاث، حفظ السجلات محليًا باسم المدرسة، التوقيع باللمس، ثم المعاينة والطباعة أو الحفظ بصيغة PDF على ورق A4 أفقي.

## النشر على Vercel

1. ارفع هذا المجلد إلى مستودع GitHub.
2. استورد المستودع في Vercel.
3. اختر **Other** في Framework Preset.
4. اترك Build Command فارغًا، وحدد **dist** في Output Directory.
5. نفّذ النشر.

لا يحتاج التطبيق إلى قاعدة بيانات أو متغيرات بيئة. تحفظ السجلات في المتصفح على الجهاز المستخدم؛ لذلك استخدم خيار النسخ الاحتياطي لنقلها أو الاحتفاظ بنسخة منها.
